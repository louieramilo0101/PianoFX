# Piano FX (Android)
Build the APK without installing anything:
1. Create a free GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab -> "Build APK" -> wait ~4 min.
3. Open the finished run -> Artifacts -> download PianoFX-apk -> unzip -> install app-debug.apk
   (allow "install unknown apps" on your phone).
Or open this folder in Android Studio and choose Build > Build APK(s).
Connect a USB keyboard with a USB-OTG adapter before launching.
